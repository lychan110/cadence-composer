Routes no HTTP routes — client-only SPA

cadence-composer is a pure client-side React 19 + Vite 6 SPA. There is no backend server, no API surface, no async channels, and no cross-repo HTTP/async edges. The "routes" below are internal pane states owned by App.jsx:
