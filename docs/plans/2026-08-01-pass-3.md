# Cadence — Pass 3 Plan

**Date:** 2026-08-01
**Status:** approved draft
**Goal:** Polish the existing composer workflow, add drag-and-drop block ordering, and finish batch export/PDF behavior.

## In scope

### 1. Drag-and-drop block reordering
- Add `@dnd-kit/core` + `@dnd-kit/sortable` for accessible, mobile-friendly reorder in BlockComposer.
- Keep existing up/down buttons as keyboard fallback until DnD is verified.
- Persist order in `blocks` array via `SET_BLOCKS`.
- Announce moves in an `aria-live` region.
- New dependency: `@dnd-kit/core`, `@dnd-kit/sortable`.

### 2. Print CSS
- Concrete scope: hide toolbar/preview chrome, set page break rules for multi-block templates, add print-safe font fallbacks, constrain image widths.
- No canvas-based PDF in this pass.

### 3. Polish
- Consistent empty states across BlockComposer, ImagePool, CsvMapper, Preview.
- Loading/error states for CSV parse and render-all.
- Toolbar action grouping and disabled states.

### 4. Batch behavior
- Keep batch HTML export via JSZip.
- Per-row print flow only; batch print deferred to later pass.

### 5. Tests
- DnD reorder dispatch test.
- Print CSS render snapshot.
- Batch render error state test.

## Out of scope

- New template block types beyond current composable HTML/markdown blocks
- Server-side persistence/auth
- Collaborative editing
- Image compression or CDN uploads
- Batch PDF print

## Implementation order

1. Add `@dnd-kit` dependencies
2. DnD in BlockComposer + keyboard fallback
3. Empty/error/loading polish
4. Print CSS
5. Tests

## Verification

- `pnpm test` remains green
- Manual dev-server check for drag-drop, empty states, and print layout
- Update README if behavior changes materially
