- Explicitly label PDF as "Print row (opens print dialog)" — no batch PDF.

### 3. Image resolution in Preview (and render)
- Resolve **all** `{{label}}` placeholders against the image pool, not just `<img src>`.

- Preview should show the fully-resolved output for the *first* CSV row if available, else placeholders.

### 4. Image preview thumbnails in ImagePool

- For base64 entries: `<img src={"data:image/png;base64," + data} width={80} />` (detect mime from data URL prefix if present).
- Keep count/size cap warning visible.
